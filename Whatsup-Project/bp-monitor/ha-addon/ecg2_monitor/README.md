# ECG2 Monitor — Home Assistant add-on

Live ECG dashboard (Ingress) for the ikinloop ecg2 BLE sensor, with a guided
connection flow, QRS heart-rate detection, session recording and MQTT-discovered
Home Assistant entities. Works with the host's Bluetooth adapter or a PC bridge over
MQTT (`../ecg_bridge.py`).

See [DOCS.md](DOCS.md) for installation, options and the guided test procedure.
