Security & Compliance

Data Protection Measures

  • End-to-end Encryption: AES-256-GCM for all uploaded documents and extracted data
  • India-only Storage: All documents stored on AWS Mumbai region, no cross-border transfer
  • Automatic Deletion: Documents auto-deleted after 7 years per DPDPA 2023 retention policy
  • Access Logging: All document access logged with timestamp, user ID, IP address
  • DPDPA Compliance: Explicit consent required, right to deletion within 30 days
  • Medical Confidentiality: Patient-doctor privilege maintained, no third-party access
  • Backup Security: Geo-redundant encrypted backups (Mumbai + Bangalore)
  • PCI-DSS Compliance: Meets Level 1 standards for payment data handling

Technical Architecture

Backend API Endpoints

POST /api/documents/upload - Upload document image/PDF - Returns: upload_id, document_uuid POST /api/documents/{document_id}/process-ocr - Start OCR processing - Returns: job_id, estimated_time GET /api/documents/{document_id}/extracted-data - Retrieve extracted fields with confidence scores - Returns: JSON with extracted fields PUT /api/documents/{document_id}/extracted-data - Update extracted data (manual corrections) - Returns: updated document state POST /api/documents/{document_id}/save-to-health-records - Save OCR data to patient's medical records - Returns: record_id, success status DELETE /api/documents/{document_id} - Delete document (DPDPA right to deletion) - Returns: deletion_confirmation

Processing Flow

1. Upload & Validation

2. Image Processing
Deskew, denoise, normalize resolution
3. Text Extraction
Tesseract + Google Cloud Vision
4. Field Detection
ML model identifies fields with confidence
5. Validation
Cross-reference, format check, medical taxonomy
6. Ready for Review
Display for manual correction & save
