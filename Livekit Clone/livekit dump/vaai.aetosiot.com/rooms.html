Rooms Management

Manage LiveKit rooms where voice/video sessions take place. Rooms are automatically created when calls connect via Dispatch Rules.

Room List

Shows all active rooms with name, status (Active/Ended), participant count, live TTFB latency, creation time, empty timeout, the Agent Name (which voice agent is handling the call), and the hosting node. Ended rooms appear dimmed with time since closure.

Live TTFB Column

Shows real-time latency metrics for active calls. Updates every 5 seconds. Color-coded: green (<500ms = good), yellow (500-1000ms = noticeable), red (>1000ms = slow). Also shows component breakdown (S=STT, L=LLM, T=TTS) when available.

Retain Room Setting

Controls how long closed rooms stay visible after ending. Options: Hide, 30s, 60s, 2min, 5min, 10min. Click the green checkmark to save your preference permanently.

Dispatch Rules & Room Types

Rooms are created automatically by Dispatch Rules when calls connect. Three types: Direct (all calls to one room), Individual (each caller gets own room), Multi-Line (room based on dialed number).

Create Room

Manually create a room with a custom name. Room names must be unique. Options include empty timeout (auto-delete when empty) and max participants limit.

Room Details

View detailed room information including metadata, creation time, active tracks (audio/video), and connected participants with their identities and connection quality.

Participant Management

View participant details including identity, connection state, audio/video tracks, and permissions. Remove participants or update their permissions.
