Recording & Storage

Manage call recordings with local and cloud storage options, bulk operations, and automatic cleanup policies.

Active Recordings

Shows recordings currently in progress with status, room name, and duration.

Local Recordings

Browse recordings stored on the local server. Supports inline playback (MP4, OGG, WebM), download, and deletion. Use checkboxes for bulk delete operations. Recordings of full-voice website chat sessions (rooms named webchat-…) are hidden unless 'Include chat sessions' is on.

Cloud Recordings

Browse recordings stored in AWS S3 or Google Cloud Storage. Supports streaming playback through the dashboard proxy, download, and bulk deletion.

Bulk Operations

Select multiple recordings using checkboxes, then use 'Delete Selected' to remove them in bulk. 'Select All' checkbox in header selects all visible recordings. Requires 'delete' permission - checkboxes are hidden for users without this permission.

Recording Retention

Recordings are kept forever by default. In Settings > Storage > Recording Storage you can set 'Delete after X days' separately for recordings on this server (applies on every storage mode — local copies can exist even with cloud storage when 'Delete local after cloud upload' is off) and for recordings archived in your S3/GCS bucket (asks for confirmation — cloud deletion is permanent). Audio files are the biggest storage users, so watch the disk usage gauge if you keep everything.

Call Recording Audio

Settings > Storage > Call Recording Audio controls how new recordings are made; settings apply from the next call with no restart. Recording Format: OGG (recommended, ~50% smaller than MP4 for voice, and required for the quality tiers' full size savings) or MP4 (maximum compatibility). Recording Channels: 'Mixed' blends everyone on both channels; 'Dual Channel' puts the agent on the left channel and the caller on the right of the same file, which makes transcription diagnostics and speaker separation far more accurate (on headphones each party plays in one ear; very old installs keep recording mixed). Recording Quality: 'Standard' keeps full quality; 'Efficient' and 'Compact' produce smaller files — the size savings apply fully with the OGG recording format (roughly half and a quarter respectively), while MP4 recordings currently shrink only slightly (a limitation of the recording component). Each recording keeps the layout and quality it was made with — switching back only affects future recordings. Defaults: new installs start with OGG + Dual Channel + Efficient; installs upgraded from earlier versions keep MP4 / Mixed / Standard until changed here.
