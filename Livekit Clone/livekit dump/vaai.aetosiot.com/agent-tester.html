How to Use

This tool lets you test your voice agents and chatbot agents directly from the dashboard via text chat or voice call.

  • Text Mode - Send text messages to the agent and receive text responses (all agents). Tests the LLM, tools and knowledge base only — the agent never listens or speaks, so speech-to-text, voice, VAD, turn detection and noise cancellation are not exercised.
  • Voice Mode - Have a voice conversation using your microphone (voice agents and full-voice chatbots). This is the only mode that tests your speech-to-text and voice settings.
  • Debug Panel - View connection events, transcriptions, and agent activity

Note: Voice agents must be running (chatbots: enabled) to respond. Test conversations don't appear in your Call or Chat History, but the agent's tools run for real.

Agent Tester

Test your voice agents AND chatbot agents via text chat or voice conversation directly from the dashboard. Useful for debugging agent behavior, testing prompts and tools, and verifying agent responses.

Getting Started

1. Select an agent from the dropdown — voice agents and chatbot agents appear in separate groups. 2. Choose Text or Voice mode. 3. Click Connect to create a test session. 4. Start chatting or speaking to test the agent.

Text Mode

Send text messages to the agent and receive text responses. For VOICE agents you can pick which LLM provider/model processes your messages via the Text Chat Settings panel. CHATBOT agents always use the model configured in their own editor (including fallbacks) — the tester shows which model that is instead of an override. Messages are sent via LiveKit data channels with full tool support.

Voice Mode

Have a voice conversation with the agent using your microphone. Requires microphone permission in your browser. The agent will respond with synthesized speech. Available for voice agents and full-voice chatbots; text-only and avatar chatbots can only be tested in Text mode.

Testing Chatbot Agents

Chatbot test sessions run the same pipeline as the website widget — same prompt, tools, knowledge base, memory, and welcome message — but in a throwaway test room: nothing is saved to Chat History (the editor's 'Preview Widget' button, by contrast, opens the real widget and DOES record history). The chatbot's webhook and other tools run for real during a test, exactly as they would for a website visitor. A chatbot must be Enabled to respond; disabled chatbots show a warning when selected.

Connection Panel
Field Description
Select Agent Choose which agent to test. Voice agents must be running; chatbot agents must be enabled
Mode Toggle Switch between Text and Voice modes (Voice is greyed out for text-only/avatar chatbots)
Connect/Disconnect Start or end the test session
Connection Status Shows current connection state
Debug Panel

The Debug panel on the right shows real-time events: connection status, participant joins/leaves, track subscriptions, data messages, and transcriptions. Useful for troubleshooting agent issues.

Requirements

Voice agents must be in 'Running' status on the Agents page; chatbot agents must be Enabled on the Chatbot Agents page. The agent's code must handle the room connection and respond to participants. If no response is received, check the agent logs.
