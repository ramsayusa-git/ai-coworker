About 2FA

Two-factor authentication adds an extra layer of security to your account. After enabling 2FA, you'll need to enter a code from your authenticator app in addition to your password when logging in.

Overview Dashboard

The Overview page provides analytics and monitoring across 9 tabs: Overview, Calls & Rooms, Latency, AI Insights, Agents, Media, Telephony, Price, and Server Stats. The top bar has a date-range dropdown (Today / Yesterday / Last 7-90 days / Custom range…), an auto-refresh toggle, and Export. Picking 'Custom range…' opens a small popover where you can choose any two dates up to 90 days apart. Export downloads the currently active tab as CSV or JSON for whichever range is active.

Date Range & Export
Field Description
Date Range Filter data by time period (Today, Yesterday, 7/14/30/60/90 days). Defaults to Today for faster loading.
Custom Range Pick any two dates up to 90 days apart. Select 'Custom range…' from the Date Range dropdown — a small picker appears with From and To date boxes and an Apply button. Click Apply to load the charts for exactly those dates, or Cancel (or press Escape, or click outside the picker) to close it without changing anything. The picker pre-fills with the preset you were on, so switching from 'Last 7 days' to Custom starts with a 7-day window selected. Once applied, all charts, pricing, and the Export button use the custom window.
Auto-Refresh Enable to update the page automatically every 30s, 60s, or 2min.
Export Download the currently active tab's data as CSV or JSON for the selected date range — works with both preset ranges and custom date ranges. Available on all tabs including Media, Telephony, Price, and Server Stats.
Overview Tab

Consolidated dashboard with key metrics: Room Connection Rate, Estimated Cost (configurable in Settings > Analytics), Answer Rate, Active Rooms, Calls Today, Running Agents, and summarized stats from other tabs including Trunk Status, SIP Success Rate, Total Calls, Total Minutes, Avg Duration, Avg Sentiment. Includes Success Status Breakdown pie chart and Call Trends graph.

Calls & Rooms Tab

Comprehensive call analytics including total calls, answer rate, call volume trends, outcomes (completed/transferred/missed/failed), direction (inbound/outbound), hourly distribution, and real-time room analytics with historical room trends. New metrics: Room Connection Rate, Longest/Shortest Call, Busiest Day/Hour, Talk Time Breakdown chart, and Call Distribution Heatmap showing call density by day and hour.

Latency Tab

Response latency metrics including API Latency, TTFB percentiles (Avg, P50, P90, P99), component breakdown (STT/LLM/TTS), hourly latency trend, and per-agent latency breakdown. Industry targets: <500ms (natural), 500-1000ms (acceptable), >1000ms (noticeable pause).

AI Insights Tab

AI-powered call analysis showing average sentiment score, pending action items, interruption rate, sentiment distribution (positive/neutral/negative), top topics extracted from calls, LLM-analyzed call outcomes, and Call End Reasons breakdown (Customer-ended vs Agent-ended with detailed reason table).

Agents Tab

Agent performance metrics including total agents, agents active today, average success rate, top performer, detailed performance table with calls/answered/success rate/minutes/duration per agent, and calls by agent chart.

Media Tab

Recording & Storage section showing active jobs, success rate, egress types chart, and storage used. Ingress/Streaming section showing active streams, connection quality, stream types, and average bitrate.

Telephony Tab

SIP trunk analytics (only visible if SIP is enabled) showing total trunks, connection success rate, trunk status, dispatch rules count, and call volume. Quick links to manage outbound/inbound trunks and dispatch rules.

Price Tab

Pricing analytics showing cost breakdown by service (LLM, STT, TTS, Realtime), total estimated cost, cost per call, cost per minute, and margin revenue. Realtime agents (audio-to-audio) appear as a separate category in the doughnut chart and stacked bar chart. Includes provider cost comparison charts, daily cost trends, and per-agent cost breakdown. Configure provider pricing rates in Settings > Analytics. Margin settings allow sub-users to see adjusted pricing with your markup applied.

Server Stats Tab

System health monitoring with Total CPU Load (1/5/15 min averages as percentages), memory usage, swap usage, disk usage, uptime, network I/O, and process count. Service Status cards show CPU% and memory for each service (Dashboard, LiveKit, Agent, Redis, SIP, Egress). CPU Usage History chart displays per-service CPU over 24 hours with auto-scaling Y-axis that adjusts to actual usage levels. CPU samples are recorded every 60 seconds.
