Dispatch Rules

Configure how incoming calls are routed to specific agents based on the dialed number.

How Dispatch Works

When a call arrives, LiveKit checks dispatch rules to find a matching agent. Rules are checked in order - first match wins.

Creating a Dispatch Rule
Field Description
Name Friendly name for this rule (e.g., 'Sales Line')
Trunk IDs Which inbound trunks this rule applies to (select one or more)
Phone Numbers Specific numbers to match, or leave empty to match all numbers on selected trunks
Agent Which agent handles matching calls
Room Prefix Prefix for auto-generated room names (e.g., 'sales-' creates 'sales-abc123')
Multi-Agent Routing

Create multiple dispatch rules to route different phone numbers to different agents. For example: Sales line → Sales Agent, Support line → Support Agent.

Default Agent

Create a catch-all rule with no phone numbers specified to handle any calls that don't match other rules.
