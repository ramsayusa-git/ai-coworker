What is this?

This tool generates JWT tokens for joining LiveKit rooms as a web participant. It's primarily used for debugging and testing.

Common use cases:

  • Debug a live call - Join a room to listen to an active voice agent conversation
  • Test room connectivity - Verify your LiveKit server is accessible
  • Developer testing - Generate tokens for custom web/mobile client development

Note: Voice agents connect via SIP trunks, not these tokens. This is a developer utility, not required for normal agent operations.

Generate temporary join tokens for testing LiveKit client connections. These tokens are created on-the-fly and never stored.
