# BP Monitor

Guided Bluetooth blood-pressure dashboard (Ingress) for the RBP1711150377
BLE cuff (ISSC BT5050 chip), with MQTT-discovered Home Assistant entities.
Companion add-on to ECG2 Monitor — same layout, same Aetos One box.
