This cuff does not use the standard Bluetooth Blood Pressure Profile — its frame format was reverse-engineered from a captured sample, so the systolic / diastolic / pulse positions have not yet been confirmed against a known-good on-arm reading. Compare the numbers shown here with the display on the cuff itself; if they differ, the byte offsets in app/protocol.py need adjusting.
