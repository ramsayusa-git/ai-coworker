## 1. System Overview

### Vision
Aetos connects patients with 2,400+ verified pharmacies across India, enabling:
- Real-time medicine price comparison
- Express 1-2 hour delivery options
- Digital prescription support
- Insurance claim processing
- Pharmacist consultations

### Key Features
1. **Pharmacy Discovery** - Location-based search with map integration
2. **Price Comparison** - Real-time pricing from 2,400+ pharmacies
3. **Smart Ordering** - One-click prescription upload & medicine ordering
4. **Delivery Tracking** - Real-time GPS tracking of medicine delivery
5. **Insurance Integration** - Direct PMJAY & private insurance processing
6. **Pharmacy Ratings** - Verified reviews with verified purchase badges
7. **Loyalty Rewards** - Points-based rewards program across all partner pharmacies

## 5. Technical Architecture & APIs

### Database Schema: Pharmacy Information

```sql
TABLE pharmacies {
  pharmacy_id (PK)
  name STRING
  rating DECIMAL(2,1)
  review_count INT
  latitude DECIMAL
  longitude DECIMAL
  operating_hours JSON
  contact_phone STRING
  contact_email STRING
  website_url STRING
  
  -- Delivery
  min_delivery_minutes INT
  max_delivery_minutes INT
  min_order_amount INT
  free_delivery_above INT
  areas_served ARRAY[STRING]
  
  -- Features
  has_24_7_service BOOLEAN
  has_video_consultation BOOLEAN
  has_insurance_billing BOOLEAN
  has_auto_refill BOOLEAN
  has_generic_alternatives BOOLEAN
  
  -- Inventory
  total_medicines_stocked INT
  last_inventory_sync TIMESTAMP
  
  -- Ratings
  avg_delivery_rating DECIMAL
  avg_quality_rating DECIMAL
  avg_service_rating DECIMAL
  
  created_at TIMESTAMP
  updated_at TIMESTAMP
}

TABLE pharmacy_services {
  service_id (PK)
  pharmacy_id (FK)
  service_name STRING
  service_type ENUM[consultation, testing, wellness_program]
  price INT (nullable)
  duration_minutes INT
  description TEXT
}

TABLE pharmacy_medicines {
  stock_id (PK)
  pharmacy_id (FK)
  medicine_id (FK)
  quantity_available INT
  unit_price INT
  gst_applicable BOOLEAN
  last_updated TIMESTAMP
}

TABLE delivery_tracking {
  delivery_id (PK)
  order_id (FK)
  pharmacy_id (FK)
  agent_name STRING
  agent_phone STRING
  vehicle_number STRING
  current_latitude DECIMAL
  current_longitude DECIMAL
  status ENUM[picked, out_for_delivery, delivered, cancelled]
  estimated_delivery_time TIMESTAMP
  actual_delivery_time TIMESTAMP
  gps_updates ARRAY[JSON]
}
```
