Frequently Asked Questions

What's the difference between ✓ and * in the checklist? ▼
✓ (Green) = Feature is fully implemented and available now.
* (Red) = Feature is planned/in development and will be added soon. This shows our roadmap transparently.
When will the missing features (*) be available? ▼
Our implementation roadmap is:
Phase 1 (2 weeks): Core compliance features
Phase 2 (4 weeks): Essential missing features
Phase 3 (8 weeks): Competitive features
Phase 4 (12 weeks): Nice-to-have enhancements
How many features are currently implemented? ▼
Currently: 42 features implemented (✓) out of 286 total = 14.7% complete.
244 features are planned (*) to be added in upcoming phases.
This ensures transparency about what's ready vs. what's coming.
Is it safe to use Aetos One Care now? ▼
Yes, absolutely safe. We have implemented 8/62 compliance standards including DPDPA 2023, NMC approval, ISO 27001, and ABDM integration. Your data is encrypted (256-bit) and stored on India-based servers only. We're adding more compliance features in Phase 1.
Why show incomplete features? Why not launch when everything is ready? ▼
Transparency is part of our core values. We believe in showing what we have, what we're working on, and when features will arrive. This builds trust and allows users to plan accordingly. Better to launch with core features and improve than to delay months waiting for perfection.
